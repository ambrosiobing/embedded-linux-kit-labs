# Every pitfall in the volume

Generated by `mdbuild.py` from the Pitfalls section of each lab, so it
is an index and never a second copy: the sentence that explains a
pitfall stays in the lab that owns it, and this page says only what the
pitfall is called and where to read it.

The order is alphabetical rather than by lab, because by lab is what the
chapters already give. The use of this page is the other direction, when
a bench is misbehaving and the lab that discussed the symptom is not the
lab being built.
