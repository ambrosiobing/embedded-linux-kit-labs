# The working record, lab by lab

Each chapter tells you what is true. These files tell you how it was arrived at,
and what was believed before it.

That second thing is usually thrown away. A volume shows its conclusions and
quietly deletes the route, so a reader cannot tell which claims were measured,
which were reasoned, and which were simply never questioned. Four claims in this
volume turned out to be wrong, and all four had looked exactly like the ones that
were right. The only thing separating them was how they came to be believed.

## What is in here

One file per lab that actually has a record. A lab with no file has nothing to
record yet, which is itself information and is why the files are not padded out
to twenty.

## What these files are not

**Not a changelog.** A changelog says what changed. These say what was believed,
why it was believed, and what it took to stop believing it.

**Not the full record.** A chronological journal is kept privately, because it
names machines, local paths and hosts that are nobody's business and help no
reader. These are the parts that generalise, with that detail removed. Nothing
substantive is held back: every withdrawal in the private record appears here.

**Not written to look good.** The most useful entries are the ones where this
volume was wrong, so those are the longest. If that reads as excessive
self-criticism, consider that the alternative is a book whose errors are
invisible and therefore repeatable.

## The rules these entries follow

**Dates in full.** Every entry carries a weekday, day, month and year, because a
bare weekday is useless six months later.

**Say which kind of knowing.** A fact is read from a vendor document, measured
with an instrument on a date, or open. The same three marks the reference page
uses. An entry that cannot say which is an entry that has not finished.

**Name what was wrong, not just what is right.** A correction that does not say
what it replaces teaches nothing, and leaves a reader who remembers the old
version unable to tell which one is current.

**A withdrawal takes the same evidence as a claim.** Retracting something because
it could not be confirmed is not the same as retracting it because it was
checked and found false. The entries say which happened.
